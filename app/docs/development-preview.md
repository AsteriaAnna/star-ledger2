## 本地数据边界

预览使用独立 IndexedDB `star-ledger-preview-m5-20261004` 和独立缓存前缀；正式账本数据库仍为 `star-ledger-next-v1`。两者在同一域名下按各自数据库读取。草稿已有设备 ID 隔离，预览新账本使用独立设备 ID；备份/同步仍是用户明确操作，不自动载入正式数据。

预览为空账本，可在“设置→体验演示账本”使用合成数据，也可自行导入。关闭页面再打开保留预览数据。不要把预览合成数据同步到个人正式同步仓库。

## 本次用户体验任务

1. 设置中开启演示账本，查看电脑与手机布局。
2. 账单详情直接改金额、账户或备注；试一下下一笔、关闭后找回未保存修改。
3. 从退款进入原消费，返回查看关联退款；更换/解除关系并确认已到账资金没有重复。
4. 导入测试文件，查看新增/重复/待补充结果；账户选择可仅用于本批；设置中查看/停止识别记忆。

目前旧手工记账表单、对账、分析下钻和部分导入补问仍未完成，不将页面预览当作功能全面验收。下次开发前先记录用户实际不便，按 M1–M7 所属节点决定优先级。

验证以固定源版本既有 367 项测试 / 36 个合成数据浏览器场景和成功 GitHub Verify 为基础；本次额外通过双目录生产构建和四项预览浏览器检查：正式/预览演示账本隔离、M5 实际财务编辑及刷新保留、双 Service Worker 与离线缓存隔离、390px 布局和脚本错误检查。既有导入浏览器证据属于固定源版本，不冒称在公网重新运行了全部测试。上线结果以 Pages 部署工作流和公开 version.json 为准。
