## 接下来按原计划推进

1. 保留 M5.1 未通过的验收门槛，本轮不宣布导入闭环完成。
2. 下一实现重点 M5.2：详情字段统一接 Correction Service，取消必填更正理由；保存自动维护关系，歧义才询问。先防止切换详情丢失未保存内容。
3. M5.3 退款关系 → M5.4 账户对账 → M5.5 分析下钻 → M5.6 花钱/收钱/转钱。
4. M6 持久化、同步、备份与性能；M7 真实设备、可用性、安全和发布门槛，详见完整评审计划。

每个旧功能分别确定保留、隐藏、自动化、合并或删除，再动页面。业务规则留在领域/账务层，界面不能自行推算余额或维护退款关系。
