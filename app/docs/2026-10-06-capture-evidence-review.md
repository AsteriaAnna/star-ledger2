## 1. 证据盘点与评分边界

离线读取30份成功API响应：15份原图、15份RapidOCR文字，均为`hy-vision-2.0-instruct`；每个case/输入路径各一份，没有将同图不同目录算成重复样本。另有一次39ms NETWORK_ERROR，无模型响应，不进入识别分母。15份现有解析器草稿和私密标准答案v0.1仍在。

|---|---:|---:|---|
| 成功响应 | 15/15 | 15/15 | 本轮重新盘点已有文件 |
| 严格JSON | 14/15 | 15/15 | 不修剪尾部文字来增加成绩 |
| total tokens | 41,118 | 13,422 | 本轮从usage重新汇总 |
| 已核验长编号 | 19/22 | 19/22 | 沿用上一轮私密逐位核对；非本轮重新读图 |

本地解析器在15份既有RapidOCR文本上仅1份产生非空日期（09）；其他14份日期为空。这个数字说明当前解析器承接不足，不等于OCR都没有读到日期，也不等于手机网页实测。

私密结果目录新增内容哈希清单`evidence-inventory-20261006.json`，用于后续确定回放输入未变；不公开原文、编号真值或原图。本文案例序号沿用原标准答案，不以内容指纹充当事件身份。

**标准答案v0.1仍是讨论基线，不冒称15项全部经用户逐项签字。** 09沿用既定亲情卡本人消费/本人不扣款口径；14无独立退款号的暂定子事件如何与后续强证据升级，属于K03规则需要落实的范围。

OCR文字路径的不同缺口同样复用：02只给一笔TRANSFER，丢原押金事件；05只给退款、moneyLines漏原支付（displayAmount仍有44）；14读到三条moneyLines却只给0.70退款；01分出本金/手续费但当前状态误取历史“银行处理中”；03/04仍当收入；11候选PAYMENT金额为负；15保持分钟但仍不知道这是已记账页面。

因此后续不能只看`candidates`，也不能认定`evidence`所有字段都可靠。截图原文、读出的字段和最终经济事件必须独立保留。

## 3. 仍缺哪些统计：不触发重跑

| 缺口 | 处理方式 | 是否需要新API |
|---|---|---|
| 全部可见文字（标题/商户/商品/零散注释）逐字真值未齐 | 复查现有原图建立字段清单，再对既有响应标正确/错误/遗漏/图中不可确定 | 否 |
| 旧22编号分母未覆盖13商品附加编号等所有数字文本 | 补充独立字段与角色；保留旧19/22历史统计，新分母另报，不能默默改成绩 | 否 |
| 金额角色、全部时间/状态/渠道尚无完整机器可读逐字段评分 | 以现有标准答案建断言，区分值正确与角色正确；未标注字段不计通过 | 否 |
| 单图多事件及05+06跨图关系没有软件执行结果 | 用保存的响应和脱敏案例执行新公共处理流程 | 否 |
| 对应Excel与截图逐事件键映射未建立 | 核对现有真实Excel是否包含对应记录，不假定已有覆盖；缺对应行先说明，再取得输入 | 否，可能需用户补文件 |
| 云上传/后台领取/断网/取消/页面编辑未实现 | 完成服务后用小组代表案例真实验证 | 到该阶段需要少量调用 |

当前不发布总体“完整识别率”或“自动入账准确率”。30次请求来自同一个模型两种输入，不是多模型对比；标准答案不得替模型补写字段再算成功。

## 4. 收紧后的行动与验收

1. **E01既有证据复核（本轮完成）**：30份成功响应去重盘点、15案例三层差异表、记录缺口与补测条件；没有新识别调用。字段全文标注未完成，不能写成全字段已评完。
2. **E02离线验收数据**：从现有真值和响应形成脱敏、可重复的字段/事件回归数据；先补全文与编号角色清单，确定真实Excel对应范围。原文继续私密保存。验收：每个失败可指向具体字段/层次，未定口径明确列出。
3. **K02任务基础、K03多事件证据**：按原小单元逐项开发；复用workspace/outcomes/导入执行/编辑与账务服务，云领取/图片寿命扩展不能替代或重建整套导入机制。K01模块已做，不重做。
4. **K04离线接入**：回放冻结响应，验证字段校验、同图多事件、跨来源身份及用户更正保护。金额用整数分；AI不能直接写余额。
5. **K05/K06真实云与页面**：先代表案例验证运输、任务与体验；只有修改模型/提示/schema或旧记录无法回答明确问题时才补识别调用，记录版本与范围。
6. **K07用户全流程验收**：15案例是回归覆盖清单，不是自动授权每阶段重跑15次API；真实调用样本范围根据已完成证据决定。安装版分享仍属于后续真机节点。

本轮没有修复截图功能、发布页面或证明真实云识别已可用。下一项是E02，完成离线验收输入后再推进K02；不越过案例直接开发整条链路。
