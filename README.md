# 星账

个人账本与关系资产视图。手机以支付详情截图快速记账，电脑以官方账单批量导入和对账；两端共用账务规则。伴侣各有独立账号和账本，绑定后可以查看授权的关系资产、近期交易及真实账户中的资金归属。
